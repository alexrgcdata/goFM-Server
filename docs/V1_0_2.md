# goFM Server v1.0.2 foundation

This increment adds request IDs, bounded recent request history, authenticated
admin overview/routes/log endpoints, failure entries, optional AES-256-GCM log
persistence, opt-in response previews, safer upstream header handling, a
FileMaker adapter contract, normalized response types, a frontend request/log
viewer, and a dedicated Go learning path.

The actual FileMaker Data API/OData transport is the next adapter increment. It
must be tested against your working FileMaker project, database, layout,
permissions, and response envelopes. The gateway will not become an open proxy:
targets, operations, fields, and mutations remain server-configured and
allow-listed.
